## Contributing

Contributions are very welcome! Please read [CONTRIBUTING.md](CONTRIBUTING.md)
before submitting a pull request.

**Quick checklist:**

- The service must be live and publicly available
- Include name, URL, and a concise, neutral description (max 120 chars)
- Add to the correct region and category
- Keep entries sorted alphabetically within each section
- Update `_data/neobanks.yml` or `_data/payment_systems.yml` for the website
